# Big Sim model showcase

A static gallery of Big Sim model renders, battlefield views, and animation previews. The published website is https://spacefoon.github.io/big-sim-model-showcase/.

The `site/` folder contains only the page, gallery images, animation previews, and credits. Raw 3D source models are not included. See [the credits](site/CREDITS.md) for original-artist attribution and scope notes.
