# Big Sim model showcase

A static gallery of Big Sim model renders, battlefield views, and animation previews. The published website is https://spacefoon.github.io/big-sim-model-showcase/.

The home page links to [Every model close-up](site/model-closeups.html), a companion gallery with 116 close-up renders for exported GLB and glTF models. Each card shows the model's source path, and [the credits](site/CREDITS.md) identify original and adapted work. The interactive [Formation drill](site/formation-drill.html) and [Cavalry crisis](site/cavalry-crisis.html) studies show infantry formations breaking under pressure and cavalry charging a forming square.

The `site/` folder contains only the pages, gallery images, animation previews, and credits. Raw 3D source models are not included. See [the credits](site/CREDITS.md) for original-artist attribution and scope notes.
